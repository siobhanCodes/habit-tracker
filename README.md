# 🌱 Habit Tracker

A simple, single-page habit tracker you can use right in your browser. Add the habits you want to build, check them off each day, and watch your streak grow. Everything is saved locally in your browser, so your data stays private on your own device.

## ✨ Features

- Add and delete habits
- Check off each day with a tap
- Rolling 7-day view for every habit
- Automatic streak counting 🔥
- Saves automatically (no account or login needed)
- Works in light and dark mode
- One file, no installation, no dependencies

## 🛠️ How it's built

The whole app is a single `index.html` file — HTML, CSS, and JavaScript all in one place. It uses your browser's `localStorage` to remember your habits between visits. No frameworks, no build step.

## 📖 How to use

1. Type a habit into the box and click **Add**.
2. Click any day's square to mark that habit done (click again to undo).
3. Your streak counts the days in a row you've completed, ending today.
